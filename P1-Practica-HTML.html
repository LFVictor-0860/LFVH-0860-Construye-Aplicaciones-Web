El objetivo fundamental de las tablas en HTML sera mostrar una serie de datos en forma ordenada organizado en filas y columnas

Para la creacion de una tabla intervienen diferentes elementos:

Table
Es la marca de comienzo de la tabla Este elemento requiere la marca de cierre
Tr
Es la marca de comienzo de una fila Esta marca debe estar dentro del elemento table
Td
Es la marca de comeinzo de una celda Esta marca debe estar dentro del elemento tr

Ejemplo

Ciudad de Mexico 9.2 millones
Guadalajara 4.1 millones
Monterrey 3.9 millones

Tabla con encabezado

La caracteristicas de esta tabla es que se le agrega a las celdas el encabezado correspondiente esto solo aplicaria a la primera fila de la tabla con la etiqueta th las demas filas usarian la etiqueta td con normalidad

Ciudad Cantidad de habitantes

Tabla con titulo
